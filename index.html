このサイトについて

個人開発者 saijack が、自分で作ったツールやサービスを公開している紹介ページです。ゲームや日々の作業をちょっと楽にする小さなツールを、個人で企画・実装しています。

作ったもの一覧

  • LoL Adviser

    LoL Adviser は、League of Legends のチャンピオンセレクト（ドラフト）画面の情報から、ChatGPT や Claude などの LLM に渡すためのアドバイス用プロンプトを自動生成する Web サービスです。

    LoL では、ドラフト状況（自分と敵のチャンピオン構成、レーン、進行タイミングなど）を踏まえた戦略アドバイスが役立ちますが、その状況を毎回自分で文章にまとめて LLM に説明するのは手間がかかります。LoL Adviser は、この「LLM に渡す前の状況整理」を代わりに行い、すぐに使えるプロンプトとして出力することで、この手間をなくすために作りました。

    使い方の流れ

    • チャンピオンセレクト画面の情報（自分と相手のピック、レーンなど）を入力する
    • LoL Adviser がその情報を整理し、LLM 向けのアドバイス依頼プロンプトを生成する
    • 生成されたプロンプトを ChatGPT や Claude などにそのまま渡して、戦略アドバイスを受け取る

    LoL Adviser を開く

    League of Legends のチャンピオンセレクト情報から、LLM に渡すアドバイス用プロンプトを生成する Web サービス。
  • MHXX 護石情報 OCR解析ツール

    MHXX 護石情報 OCR解析ツール は、モンスターハンターXX（MHXX）の護石一覧画面のスクリーンショットをアップロードすると、1枚の画面に表示されている護石（最大9件）をまとめてOCRで自動解析し、CSV形式でダウンロードできる Web アプリケーションです。

    護石の情報をひとつずつ手入力で記録するのは手間がかかるため、スクリーンショットから直接まとめて読み取り、その場で内容を確認・修正しながらリスト化できるようにするために作りました。サーバーを使わず、ブラウザ内で完結して動作します。

    MHXX 護石情報 OCR解析ツールを開く

    モンスターハンターXXの護石一覧画面をOCRで自動解析し、CSV形式でダウンロードできる Web アプリ。
